## ⚙ Features

* **Automated View Generation** - Sends simulated view requests to YouTube’s public endpoints, incrementing view counts based on realistic user-agent and behaviour emulation.
* **Proxy Rotation** - Integrates HTTP, HTTPS, and SOCKS5 proxies with automatic rotation to avoid IP blocks and distribute view requests across multiple networks.
* **Custom Scheduling** - Allows users to set hourly, daily, or weekly schedules for view campaigns, with support for randomized intervals and burst modes.
* **Multi-Session Management** - Runs simultaneous bot sessions with separate configurations, enabling parallel campaigns on multiple videos or channels.
* **Geo-Targeted Views** - Emulates views from specific countries or regions by pairing proxy IPs with location metadata for targeted audience growth.
* **User-Agent Spoofing** - Configurable HTTP headers and user-agent strings to mimic desktop and mobile clients, enhancing authenticity of view traffic.
* **Configurable View Patterns** - Supports gradual ramp-up, peak-and-drop, and steady-view patterns to replicate natural viewer behavior over time.
* **Detailed Analytics Reporting** - Exports comprehensive CSV and HTML reports, including total generated views, session logs, proxy performance, and error breakdowns.
* **Session Resumption** - Automatically saves campaign state and progress to resume interrupted sessions without duplicating views.
* **IP Blacklist Management** - Detects and excludes proxies that return errors or captchas, maintaining a healthy proxy pool for uninterrupted operation.
* **Email & Webhook Notifications** - Sends real-time alerts upon campaign start, completion, or errors via email or custom webhook endpoints.

And many other features!
